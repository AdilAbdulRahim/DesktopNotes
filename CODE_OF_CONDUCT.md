# Contributor Covenant Code of Conduct (v2.1)

Our community is dedicated to providing a welcoming and respectful environment for everyone. By participating in this project, you agree to abide by this Code of Conduct.

Standards
- Be respectful and considerate in interactions.
- Avoid discriminatory, harassing, or abusive behavior.
- Assume good faith and be constructive in feedback.

Enforcement
If you experience or witness behavior that violates this Code of Conduct, please report it to the maintainers at maintainers@yourdomain.example. All reports will be handled confidentially.

For the full text, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
