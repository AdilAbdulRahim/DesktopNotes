# Code of Conduct

I want DesktopNotes to be a welcoming and respectful project for everyone. By participating, you agree to treat others with respect and follow this Code of Conduct.

## Expected behavior

- Be considerate and respectful in discussions and reviews.
- Give and receive constructive feedback in good faith.
- Make space for people with different backgrounds and experience levels.

Unacceptable behavior includes harassment, discrimination, personal attacks, and other conduct that makes the project unsafe or unwelcoming.

## Reporting

If you experience or witness unacceptable behavior, please email me at [adilrahim22@gmail.com](mailto:adilrahim22@gmail.com). I will handle reports as privately as I can and take appropriate action.

This code is informed by the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
